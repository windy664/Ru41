# 目标

能读懂并写出安全的 Rust 代码，能独立写出一个带测试的 CLI 工具。

**不追求**：完整语言覆盖、宏、unsafe、异步、并发 —— 那些放寒假。

# 为什么只学"基础"

学期内每周可用整块 13 块、碎片 90 分钟，且四级（12-19）与 HICP（12-31）两个硬锚定
会占满大部分整块。实测下来，**这学期现实能同时推进的目标最多两个**（见
[ai-planner-sim.md](ai-planner-sim.md)）。Rust 作为无外部锚点的日常型目标，
必须缩到一个能被整块承载的范围 —— 所以定"基础"，不定"完整 Rust"。

完整 Rust 路线约 90 小时，寒假 8 周 × 8 小时 = 64 小时，加上学期内零星投入刚好够。
**学期内打地基，寒假做完整项目。**

# 验收标准

- 能读懂并修复借用检查器的三类报错
- 能用 `Result` + `?` 组合错误流，且错误信息对用户可读
- 能用 trait 抽象行为、用泛型约束类型
- 能判断何时需要手写生命周期标注、何时编译器能推出来
- 能从零写出一个带测试的 CLI 工具

# 停止条件

出现下面任一情况就重新评估这个目标（不要硬撑）：

- 连续两周安排的整块**一个都没做** → 不是时间问题，是目标选错了
- 每周投入低于 2 小时 → 达不到基础水平，缩到"只读 Book 不动手写"或直接延到寒假
- 同期有更硬的锚定目标（四级/雅思/HICP 报名截止）→ Rust 让位，这是设计好的

# 每周节奏

周一晚 19:00-21:00 + 周日上午 10:00-12:00，各 2 小时（= 4h/周）。

> 槽位不是随手定的：它由 [scripts/plan-sim.py](../scripts/plan-sim.py) 从真实课表算出
> 「可用块数 × 间隔天数」的最优组合，周三晚被思政课占了 5 周，不能用。
