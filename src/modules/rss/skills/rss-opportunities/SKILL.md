# 机会雷达查询

## 数据在哪

- 历史日报：`/vault/05-Opportunities-机会/雷达-日报/<日期>-digest-<id>.md`，每天最多两份（08:00 早报、21:00 晚报），文件名按日期排序，读最新的几份即可。
- 日报由 Ru41 rss 模块生成：8 个订阅源（HN、HuggingFace、V2EX、ProductHunt、CSDN 极客快讯、IT之家、极客公园、r/LocalLLaMA）全天入池，到点由 GLM 按用户关注方向精选。

## 怎么回答

- 「最近有什么机会」：读最近 2-3 份日报，按主题归并（免费额度 / 竞赛 / 实习 / 行业动态），标注信息来自哪天的哪份报。
- 「今天有什么新的」：今天还没出报时，说明下一份报的出报时间（08:00 / 21:00），并基于最近一份日报回答；不要声称能拿到池子里未精选的实时条目。
- 已过期的机会（领取截止、报名截止已过）明确标注「已过期」，不要当成可操作项推荐。

## 纪律

- 不要手动运行 `rss poll`：它只往池子里攒条目，不会提前出报，跑了用户也看不到新东西。
- 日报内容区分事实与推断是设计口径，转述时保持这个区分，别把推断说成事实。
- 用户想调整关注方向或源列表时，说明这需要改配置（`[sources.rss]` 的 interests/feeds），不要假装能当场改。
