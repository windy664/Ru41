# arXiv 论文研究

1. 先明确主题、时间范围、分类和任务类型（检索、筛选、跟踪、比较或精读），不要扩大用户给定的范围。
2. 优先使用 arXiv API、论文页面或用户提供的论文原文。记录并保留 arXiv ID 和可访问链接。
3. 区分摘要、全文与外部评论：摘要支持的观点只能概括为论文自述，不能把外部评论写成论文结论。
4. 对每篇论文分别给出题名、arXiv ID、链接、与主题的相关性及判断依据。未能核实的信息明确标记，不要补写作者、发布日期、实验数据或引用量。
5. 精读时先概括问题、方法、证据和局限，再说明与当前任务的关系。需要完整证据时先获取全文，不要只凭标题推断。
6. 默认用简洁中文输出；保留论文原名、专业术语和链接，方便用户继续核查。
