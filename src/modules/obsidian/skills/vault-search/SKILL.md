# Vault 知识库检索

## 环境

- Vault 挂载在 `/vault`，**只读**。不要写入、移动或删除任何文件。
- 知识库是用户的私人数据：只读取与问题相关的笔记，不要遍历无关目录（尤其 04-Life 下的私人记录）。

## 目录结构

- `00-Inbox-收件箱/`：未整理的新笔记（快速记录先进这里）
- `01-Courses-课程/<学期>/<课程>/`：课程作业与说明
- `02-Projects-项目/`：项目（Active-进行中 / Research-研究 / Archived-已归档）
- `03-Knowledge-知识/`：学习笔记（按领域分目录）
- `04-Life-生活/`：生活记录（日志、消费、规划）——私人程度高，非必要不读
- `05-Opportunities-机会/`：竞赛、科研、实习、黑客松等机会情报
- `06-Blog-博客/`：Drafts-草稿 / Published-已发布

## 检索方法（先宽后窄）

1. 全文搜关键词：`rg -i -l "关键词" /vault`，同义词各试一次（中/英、缩写）
2. 按目录收窄：`rg -i "关键词" "/vault/03-Knowledge-知识"`
3. 命中后用 Read 读全文再回答；没命中就换关键词或直说没有
4. 文件名本身也是线索：`rg --files /vault | rg -i "模式"`

## 回答要求

- 注明来源：回答末尾列出参考的笔记路径（相对 /vault）
- 笔记里没有的信息不要编；可以说「知识库中没有相关记录」
- 内容可能过时：留意笔记的日期，涉及时间敏感信息时提醒用户
