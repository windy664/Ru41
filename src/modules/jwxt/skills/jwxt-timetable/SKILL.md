# 课表查询

课表是「行程」的一种来源，但课程信息（教师、教室、节次、周次）比日程事件更细，走 jwxt 专属入口查询。

## 查询（经 CLI，配置文件用任务注入的路径或 `--config`）

- `ru41 jwxt classes`：今天的课。
- `ru41 jwxt classes tomorrow`（或 `明天`）：明天的课。
- `ru41 jwxt classes 2026-10-24`：任意日期（YYYY-MM-DD）。
- `ru41 jwxt classes week`（或 `周`）：从今天到周日的整周课表。

输出是 Markdown（含日期、周次、每门课的起止节次与时刻、教室、教师），可直接整理后回复用户。

## 规则

1. **只读缓存**：该命令不触网、不需要登录态。如果输出提示"暂无课表缓存"，说明 jwxt 同步尚未成功（通常是学校系统不可用），如实告知，不要编造课程。
2. 跨多天的比较类问题（"这周哪几天有早八""周三下午空吗"）用 `week` 一次拉全再分析，不要逐日多次调用。
3. 课表改动（调课/停课）由 jwxt 监控自动推送，你不用主动检测变更。
4. 用户要**新增/取消**课程相关的日程提醒时，改用 personal-schedule skill 的 `ru41 event` 入口（课表事件本身是 jwxt 拥有的，不要替它创建或删除）。
5. 默认简洁中文回答；区分「课表上有的」与「你的推断」。
