# Vault 知识库检索

## 环境

- Vault 挂载在 `/vault`，**只读**。不要写入、移动或删除任何文件。
- 知识库是用户的私人数据：只读取与问题相关的笔记，不要遍历无关目录（尤其 04-Life 下的私人记录）。

## 目录结构

- `00-Inbox-收件箱/`：未整理的新笔记（快速记录先进这里）
- `01-Courses-课程/<学期>/<课程>/`：课程作业与说明
- `02-Projects-项目/`：项目（Active-进行中 / Research-研究 / Archived-已归档）
- `03-Knowledge-知识/`：学习笔记（按领域分目录）；`School-学校/` 子目录收录学校官方文件（《学生手册》等），**学校政策类问题（学分/综测/奖惩/资助等）优先查这里**
- `04-Life-生活/`：生活记录（日志、消费、规划）——私人程度高，非必要不读
- `05-Opportunities-机会/`：竞赛、科研、实习、黑客松等机会情报
- `06-Blog-博客/`：Drafts-草稿 / Published-已发布

## 检索方法：多路扩词，一次问不准就换词再问

用户的用词和文件里的正式叫法常常不一致（问「单项励志金」，手册写「单项奖励金」）。
**一次检索没命中不等于没有**——按下面的方式换词多路再查。

### 1. 先用语义检索拿方向

```bash
ru41 --config /etc/ru41/config.toml --db /data/state.db knowledge search "<用户问题的核心说法>"
```

向量索引覆盖全部笔记，记不清准确关键词时也能命中。命中后用 Read 读 `/vault/<path>` 全文再回答；
score 低于 0.4 的结果可信度低，要交叉验证。

### 2. 关键词多路并查（同义词 OR 在一条命令里）

别一条一条搜，直接把候选词用 `|` 串起来一次搜：

```bash
rg -i -l "励志金|奖励金|奖学金|单项奖" /vault/03-Knowledge-知识
rg -i "励志金|奖励金|奖学金" "/vault/03-Knowledge-知识/School-学校/学生手册（2026年9月版）.md"
```

同义/近义/全称/缩写/英文都要想到，一次命令覆盖：

- 中文近义：励志金 ≈ 奖励金 ≈ 奖学金 ≈ 单项奖励金
- 全称与简称：五史 ≈ 中国近现代史纲要；体测 ≈ 体质测试；综测 ≈ 综合测评
- 英文：rubric ↔ evaluation criteria、transcript ↔ 成绩单
- 常见错字：单词换形、别字（"励志"↔"奖励"）

### 3. 逐级放宽关键词

先搜完整短语，再逐步缩短（**长词搜不到就换短的**，反之亦然）：

`单项励志金` → `单项` → `奖励金` → `金`（配合"评选/条件/申请/办法"等词定位条款）

条款类问题优先搜**条款编号与关键词的组合**：`第十三条`、`单项奖励金`、`评选条件`。

### 4. 学校文件只读 md 源，不要下载/渲染 PDF

`03-Knowledge-知识/School-学校/` 里的手册**已经有 md 全文**（条款连续、带章节标题）。
手册 PDF 体积大且是扫描/排版件，**逐页渲染会烧光工具预算**（2026-11-05 曾因此连续超时三次）。
要引用条款就读 md 源文件；要原文截图再考虑 PDF。

### 5. 检索报错

`knowledge search` 报错（索引未建）时，提醒用户运行 `ru41 knowledge index`。

## 回答要求

- **注明来源**：回答末尾列出参考的笔记路径（相对 /vault），条款类问题给出条款号
- **名称对不上要说明**：用户用的词和文件里的正式叫法不同时，先说明两者是同一件事
- 笔记里没有的信息不要编；可以说「知识库中没有相关记录」
- 内容可能过时：留意笔记的日期，涉及时间敏感信息时提醒用户
