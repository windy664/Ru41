# 通义听悟：音视频 → 逐字稿

## 什么时候用

用户发来**音频/视频文件**并想要文字版（"转成文字""逐字稿""他说的是什么""整理一下录音"）。
QQ 的**纯语音消息**平台已经给了 ASR 文本（prompt 里是 `[语音转写] …`），那种**不用**调本工具；
本工具针对的是**文件**（mp3/m4a/wav/mp4…）和**视频**。

## 和课堂录音那条路（lecture 插件）的区别

- `lecture` 插件：QQ 语音消息 → ffmpeg 切片 → OpenAI 兼容 ASR（智谱 GLM / whisper.cpp）→
  转写内联进 prompt + 笔记写 Vault。**没有说话人分离**，要另配 ASR key。
- 本工具：通义听悟（用户自己的账号额度）→ **带时间戳 + 说话人分离**的逐字稿落盘。

用户要「谁在什么时候说了什么」就用本工具；要「课堂笔记」走 lecture 那条。

## 怎么转

1. **先把附件下载到本地**。QQ/Telegram 的附件在 prompt 里给的是**有时效的下载地址**：

   ```bash
   curl -sL -o /tmp/meeting.mp3 "<地址>"
   ```

   下载完先确认拿到的是真文件（别把 403 的 HTML 当成音频传上去）：

   ```bash
   ls -l /tmp/meeting.mp3 && file /tmp/meeting.mp3
   ```

2. **转写**（要等，音频长的话几分钟到十几分钟）：

   ```bash
   ru41 tingwu transcribe /tmp/meeting.mp3
   ```

   输出是一段 JSON，关键字段：
   - `trans_id`：听悟任务 ID（以后取稿子用它）
   - `markdown_path`：逐字稿 Markdown 的落盘路径（**这是正文所在**）
   - `files`：写出来的所有文件（`.md` 正文、`.json` 原始逐字稿）
   - `duration_secs` / `word_count` / `speakers` / `segments`：时长、字数、说话人数、段落数
   - `preview`：正文前 200 字（**只是预览，不是全文**）

3. **读全文**：用 read 工具读 `markdown_path` 那个 `.md` 文件。不要拿 `preview` 当全文回复。

4. **回复用户**：逐字稿正文（长的话按说话人分段给）+ 一行元信息（时长/字数/说话人数）。

## 要点

- **逐字稿以落盘的 `.md` 为准**。命令返回的 `preview` 只是开头几百字。
- **说话人编号**从 1 起（听悟原始 `si` 是 0 起的，插件已 +1）。
- **别编造**：命令报错（cookie 失效、文件太大、听悟拒绝）就把报错原样告诉用户，
  **不要**根据语音内容猜一段文字出来。
- **cookie 在凭据托管库里**（标签 `tingwu-cookie`），不在配置文件里。如果报「没有名为
  tingwu-cookie 的凭据」，说明登录态过期了 —— 让用户在 QQ 里说
  「帮我记住 tingwu-cookie 的值是 <新的整串 cookie>」，或自己执行
  `ru41 secret set tingwu-cookie '<整串 cookie>'`。**不要**让用户把 cookie 发在普通对话里。
- **单文件上限 500 MB**（听悟网页版的限制）。超大文件要提示用户分段。
- 一次转写一个文件；用户一次发多个就依次转，不要并发（听悟对并发敏感）。

## 其它子命令

- `ru41 tingwu list [条数]`：账号里的历史转写任务（任务 ID、名称、状态、时长、字数）。默认 10 条。
  用户问「上次转的那个稿子呢」用这个找 `trans_id`。
- `ru41 tingwu result <任务ID>`：取**已有**任务的逐字稿（不重新转写，也不占听悟额度）。
  `--format text` 出纯文本（每行 `[时间戳] 说话人N：…`），`--format srt` 出字幕文件。

## 格式选项

`ru41 tingwu transcribe <文件> [--format markdown|text|srt]`

- `markdown`（默认）：`.md` 正文，**按说话人分段 + 时间戳**
- `text`：额外写一份 `.txt`（每行一句，带时间戳与说话人编号）
- `srt`：额外写一份 `.srt` 字幕（按句切，可直接挂到视频上）

不管选哪个，`.md` 和 `.json`（原始逐字稿）都会写。
