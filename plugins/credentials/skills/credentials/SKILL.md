# 凭据托管

用户在 QQ 里说「帮我记住 xx 的密码是 xxx」时，凭据已在网关层入库（没进会话记录）。本技能管「怎么用」。

## 铁律：真值不进上下文

- 在 shell 命令里用 `$(ru41 secret get <名称>)` 内联展开，例如：
  `curl --user "kjdown:$(ru41 secret get ftp_upload)" ftp://172.16.3.242/...`
- **不要**单独运行 `ru41 secret get <名称>` 把真值打印出来看——那就泄漏进上下文了。
- 命令的输出如果可能回显凭据（如调试回显），加静默处理或重定向。

## 名单与删除（用户用自然语言问时）

- 「我存了哪些凭据」→ 运行 `ru41 secret list`（只有名称），原样回答。
- 「把 xx 的凭据删了」→ `ru41 secret delete <名称>`，删除后回复确认。

## 缺凭据时

任务需要凭据而库里没有（`ru41 secret get` 报不存在）时，回复用户：
「请发『帮我记住 <名称> 的密码是 <值>』，我会从托管库自取。」
不要让自己索要明文后在对话里使用——收到的明文会被脱敏成假值，用不了。

## 假值识别

上下文里看到 `key_<24位hex>` 形态的占位值，说明原文被入口脱敏替换过——真值可能在托管库，先 `ru41 secret list` 找名字。
